# Roadmap Builder

Prompts that build a learning roadmap for any subject.

## Files

- `roadmap_builder.md` — groups topics into levels, chapters and lessons
- `roadmap_builder_v2.md` — groups topics into Themes. Themes are more dense and every topic appears only once, so it is more effective

## Usage

Fill in the fields at the top of the prompt file:

- `SUBJECT` — what you want to study;
- `CURRENT_LEVEL` — what you already know;
- `GOAL` — the level you want to reach;
- `COMMENTS` — extra requirements; can be left empty.
